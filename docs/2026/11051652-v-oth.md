## 一、gnome-system-monitor（GNOME 系统监视器）版本选择（2026-11-05 定稿：2.28.2） ✅ 已实现

### 1.1、GTK2 兼容的最后一版 = 2.28.2

- gnome-system-monitor 是 **C++/gtkmm** 应用，是 GNOME 桌面的任务管理器。
- **版本 tag 证据**：`git ls-remote --tags` 显示 2.x 系列最后一个 tag 是
  `GNOME_SYSTEM_MONITOR_2_28_2`，之后**直接跳到 `GNOME_SYSTEM_MONITOR_2_99_0`**（GTK3 开发版），
  **没有 2.30/2.32 系列**。
- **GNOME 2.32.0（2010-09）发布版本表**里 `desktop:gnome-system-monitor:2.28.2`——GNOME 2.32
  发布时系统监视器仍是 2.28.2，即 2.28.2 之后未再发 2.x 稳定版。
- **Bug 632799**（2010-10-21 报告，2011-02-11 合并进 master）：Chris Kühl 在 gtk3 分支完成
  GTK3 移植并 merge 进 master → **3.0.0（2011-04-04）已是纯 GTK3**。
- 3.0.0 起硬编码 gtkmm-3.0：2012-09-27 提交 configure.ac 已用 `GTKMM_REQUIRED=3.3.18`、
  `GTK_REQUIRED=3.0`、`LIBGTOP_REQUIRED=2.28.2`。
- **选 2.28.2**：GTK2/gtkmm-2.4 最后一版（2.28.2 之后源码树即切 GTK3，无 GTK2 分支可回退）。

### 1.2、版本/依赖对照

| 版本 | 日期 | GTK 绑定 | 说明 |
|---|---|---|---|
| 2.28.2 | 2010-09 | gtkmm-2.4 + gtk+-2.0 | **GTK2 最后一版**（GNOME 2.28/2.30/2.32 均用它） |
| 2.99.x | 2011-01~03 | gtkmm-3.0（gtk3 分支） | GTK3 开发过渡版 |
| 3.0.0 | 2011-04-04 | gtkmm-3.0 硬编码 | 纯 GTK3（GNOME 3.0 首版） |

### 1.3、依赖清单（2.28.2 configure.in PKG_CHECK_MODULES(PROCMAN)）

`glib-2.0>=2.16.0 gconf-2.0>=1.1.5 libgtop-2.0>=2.23.1 libwnck-1.0>=2.5.0 gtk+-2.0>=2.20.0
gnome-icon-theme>=2.15.3 gtkmm-2.4>=2.8 libxml-2.0>=2.0 librsvg-2.0>=2.12 glibmm-2.4>=2.14
giomm-2.4>=2.16 dbus-glib-1>=0.7`

额外构建依赖：`IT_PROG_INTLTOOL`（intltool）、`AM_GCONF_SOURCE_2`（gconf 源码宏）、
`AC_PROG_CXX` + `CXXFLAGS="-std=c++98"`（C++98 编译）。

### 1.4、本项目基础设施适配

- **✅ 已就位（box 实测）**：
  - `gtk+-2.0`：u-gtk 2.24.33 静态（`/usr/lib/libgtk-x11-2.0.a`，含 murrine/pixmap/file/lpr 打印后端）。
  - `glib-2.0/gio-2.0/pango/cairo/atk/gdk-pixbuf`：u-gtk 静态树 `/usr/lib/*.a`（含 gdk-pixbuf 内置
    svg/png/jpeg loader）。
  - `librsvg-2.0`：`/usr/local/lib/librsvg-2.a`（v-tint2 `librsvg()`，STATIC=yes）。
  - `libxml-2.0`：`/usr/lib/libxml2.a`（apk 包）。
- **❌ 真缺口（7 个硬依赖，比 pavucontrol 的 3 个更重）**：box/awe 当前**都没有**：
  - `gtkmm-2.4`（C++ 封装，依赖 atkmm-1.6/gdkmm-2.4/pangomm-1.4/cairomm/giomm/glibmm/sigc++-2.0）
  - `glibmm-2.4`（gtkmm 依赖）
  - `giomm-2.4`（gtkmm 依赖）
  - `libgtop-2.0`（**核心系统监控数据源**，无它即无 CPU/内存/进程数据）
  - `libwnck-1.0`（窗口管理库，依赖 gtk + X）
  - `dbus-glib-1`（DBus GLib 绑定）
  - `gconf-2.0`（GNOME 2 配置系统，**依赖 ORBit2 CORBA 栈**，最重的老依赖）
- **说明**：`gnome-icon-theme`（主题）是运行时资源非构建依赖，可后续按 openbox 主题方式处理。

### 1.5、结论

- **选 2.28.2** 作为 gnome-system-monitor 静态编译版本（GTK2/gtkmm-2.4 最后一版）。
- **前置工作（比 pavucontrol 明显更重）**：
  ①构建 `gtkmm-2.4` 全套（glibmm/giomm/atkmm/gdkmm/pangomm/cairomm/sigc++）；
  ②构建 `libgtop-2.0`；③构建 `libwnck-1.0`；④构建 `dbus-glib-1`；
  ⑤构建 `gconf-2.0`（含 **ORBit2 CORBA** 前置，最重）。
- **⚠️ 最大障碍**：gconf-2.0 + ORBit2（CORBA/IIOP）是老 GNOME2 栈，静态链接成本高、
  依赖面广；需评估是否可 patch 掉 gconf（系统监视器仅用它存偏好设置），或接受重依赖。

## 二、engrampa（MATE 压缩管理器）版本选择（2026-11-05 定稿：1.14.1） ✅ 已实现

### 2.1、GTK2 兼容的最后一版 = 1.14.1（2016-05）

- engrampa 是 **C**（非 C++）应用，MATE 桌面的压缩管理器（file-roller 的 MATE 版）。
- **1.7.x** 加入 GTK3 支持：`--with-gtk=3.0` configure flag（**同时支持 GTK2/GTK3 双模式**）。
- **1.10.0**：统一 Gtk+2/Gtk+3 代码，Drop support for Gtk+ < 2.24。
- **1.16.0（2016-06，PR #140）**：Move to GTK+3（require GTK+ >= 3.14），**drop GTK+2 code 和
  `--with-gtk` 选项** → 纯 GTK3。
- **选 1.14.1**：GTK2 最后一版（1.14.1 configure.ac 仍 `--with-gtk=2.0|3.0`，默认 2.0）。

### 2.2、版本/依赖对照

| 版本 | 日期 | GTK 绑定 | 说明 |
|---|---|---|---|
| 1.7.x~1.14.1 | 2014-05 | gtk+-2.0/3.0（`--with-gtk` 可切） | **GTK2 可用** |
| 1.16.0 | 2016-06 | gtk+-3.0 >= 3.14 硬编码 | 纯 GTK3 |

### 2.3、依赖清单（1.14.1 configure.ac）

`PKG_CHECK_MODULES(GTK, [gtk+-2.0 >= 2.24.0])`、
`PKG_CHECK_MODULES(FR, glib-2.0>=2.32.0 gthread-2.0 gio-unix-2.0>=2.25.5 gtk+-2.0>=2.24.0)`

可选（本项目均无，可跳过）：
- `libcaja-extension >= 1.1.0`（**默认启用**；MATE 文件管理器扩展，本项目无 caja →
  **必须 `--disable-caja-actions`**，否则 PKG_CHECK_MODULES 直接报错）。
- `json-glib-1.0 >= 0.14.0`（PKG_CHECK_MODULES 四参，缺失自动关）。
- `libmagic`（`--enable-magic` 默认 no）。
- `packagekit`（默认 yes，仅 `AC_DEFINE` 不 PKG_CHECK，不影响构建）。
- 构建时：`intltool >= 0.50.1`、`gettext`、`libm`（`AC_CHECK_LIB(m, floor)`）。

### 2.4、本项目基础设施适配

- **✅ 全部就位（box 实测）**：`gtk+-2.0`（u-gtk 2.24.33）、`glib-2.0`、`gthread-2.0`、
  `gio-unix-2.0`（u-gtk 静态树 `/usr/lib/*.a`）。
- **❌ 无真缺口**：唯一要处理的是 caja-actions（默认开、MATE 专属）——配置时加
  `--disable-caja-actions`；json-glib/libmagic/packagekit 均可选，缺失自动跳过。

### 2.5、结论

- **选 1.14.1**：GTK2 最后一版，**无真缺口**，加 `--disable-caja-actions` 即可在现有
  gtk2 静态树上构建。

#### 3.2.4、结论

- 建议：可与 thunar（6.4）同批（共享 xfce 库栈）；先建 libexif，再 ristretto。
