### 2、clipit 静态化实现过程与总结（2026-11-24，builder-g224）

#### 2.1、源码与选型

- **源码**：`github.com/CristianHenzel/ClipIt` @ commit `f35db54`（2024-11-03；Fedora 打包为 `1.4.5^20241103gitf35db54`）。
  取 commit 快照而非 tag `v1.4.5`（2020-06）——C99 构建修复在 2024-11 commit 里。
- **栈**：GTK2 默认（configure.ac `PKG_CHECK_MODULES([GTK], [gtk+-2.0 >= 2.10])`；`--with-gtk3` 不用），
  `--disable-appindicator`（静态栈无 ayatana-appindicator）。
- **运行时依赖 xdotool**：`main.c:342` `/bin/sh -c 'xdotool key ctrl+v'`（自动粘贴）→ **b_deps 静态建 xdotool**。

#### 2.2、构建踩坑（逐个，均落仓）

1. **GdkSeat 是 GTK3-only**（`main.c:212`、`daemon.c:60` 用 `gdk_display_get_default_seat`/`gdk_seat_get_pointer`，
   上游 GTK3 适配泄漏到 GTK2 分支，无版本宏保护）→ `clipit-gtk2-seat.patch`：GTK2 等价
   `gdk_window_get_pointer(window, NULL, NULL, &button_state)`。
2. **gtk_box_new / gtk_widget_render_icon_pixbuf 是 GTK3-only**（preferences.c 约 28 处 gtk_box_new、
   manage.c 2 处、main.c:386/manage.c:143/351/preferences.c:735 render_icon_pixbuf）→ `clipit-gtk3-api.sed`：
   `gtk_box_new(GTK_ORIENTATION_*，s)` → `gtk_vbox_new/gtk_hbox_new(FALSE, s)`（GTK2 是 `(homogeneous, spacing)` 2 参）；
   `gtk_widget_render_icon_pixbuf(w, stock, size)` → `gtk_widget_render_icon(w, stock, size, NULL)`。
3. **链接走 `$(LINK)` 非 `$(clipit_LINK)`**（`src/Makefile:397`）+ `clipit_LDADD` 含动态 GTK_LIBS（会优先 .so → 动态链）
   → 覆盖 `LINK="xx-clang -static -no-pie ..."` + `clipit_LDADD=""` + `LIBS="$CLI_LIBS"`（start-group 静态全链）。
   首次漏覆盖产出 **dynamically linked** 12.9M（非静态），修正后 `statically linked, stripped`。
4. **xdotool 缺 libXtst.a**：alpine 无 `libxtst-static` 包；g-system `fk-libxtst` 私有需认证；上游在
   **gitlab.freedesktop.org**（github 无镜像）→ 用 **x.org 官方 tarball** `libXtst-1.2.4.tar.gz`
   （1.2.5/1.2.3 在 x.org 404），`./configure --prefix=/usr --disable-shared --enable-static`。
5. **xdotool 是扁平 Makefile**（根目录直接 cmd_*.c，无 autotools）→ 用其 `static` 目标
   `make static CC=xx-clang LDFLAGS="-static -no-pie" ...`；链接缺 `xcb_*`（libX11.a 依赖 libxcb）
   → 补 `-lxcb -lxcb-render -lxcb-shm -lxcb-util`。
6. **下载慢**：github 直连/archive 下载慢或超时（`git ls-remote` 通但 clone/archive 慢）→ **ghfast.top 前缀代理兜底**；
   x.org tarball 更快。clipit/xdotool/libXtst 下载均走 `down_catfile`（tarsrc 缓存）+ ghfast 兜底。
